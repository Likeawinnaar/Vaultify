# Vaultify

Vaultify is an open-source encrypted file-storage platform concept with a separate, professional admin console.

## Included in this prototype

- Responsive admin navigation for dashboard, users, administrators, storage, registration, security, app settings, and audit log.
- Realistic system metrics, storage overview, recent activity, and security events.
- Searchable user management table with role, status, usage, and quota visibility.
- Server-side security principles reflected in the UI: primary administrator protection, no password or secret exposure, and encryption status shown without keys.
- “Support LW Development · Help us reach 10K” sidebar touchpoint.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

This repository currently contains the front-end prototype. Authentication, persistence, encrypted object storage, and server-side authorization should be implemented before production use.
